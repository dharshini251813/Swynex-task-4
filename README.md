# Lumora — Student Life Planner

Lumora is a responsive student productivity web app built with HTML, CSS, and vanilla JavaScript. It helps students organize tasks, track progress, save notes, and complete focused study sessions.

## Features
- Responsive dashboard with task statistics and daily progress
- Create, edit, complete, search, filter, and delete tasks
- Task category, due date, and priority labels
- Focus timer with 15-, 25-, and 45-minute sessions
- Quick notes: create, edit, and delete
- Saves tasks, notes, and focus minutes in browser local storage
- Mobile-friendly navigation and layout
- No external libraries or paid services required

## Technologies
- HTML5
- CSS3 (responsive layout and styling)
- JavaScript (DOM, timer, and localStorage)

## How to run
1. Download or clone this repository.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Start creating tasks and notes. Your data is saved in the same browser on the same device.

No installation or build command is required.

## Project structure
- `index.html` — complete app (markup, styles, and JavaScript)
- `README.md` — project documentation
- `DEMO_SCRIPT.md` — short walkthrough script for the demo video
- `SCREENSHOTS.md` — guidance for adding screenshots

## Data and privacy
Lumora stores app data in the browser's localStorage. Data is not sent to a server. Clearing browser data or using a different browser/device may remove or not show saved items.

## Limitations
This is a front-end learning project. It does not include user accounts, cloud sync, or a remote database. Focus timer minutes are recorded when a session finishes normally; refreshing the page during a running session resets the timer.
