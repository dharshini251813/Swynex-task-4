# Screenshots for your submission

The internship instructions ask you to add screenshots. After opening `index.html` in your browser:

1. Open the Overview page and capture a screenshot.
2. Add a few sample tasks, then capture My Tasks.
3. Open Focus Room and capture the timer.
4. Add a sample note and capture Quick Notes.
5. Save the images in this `screenshots` folder using names such as:
   - `01-overview.png`
   - `02-my-tasks.png`
   - `03-focus-room.png`
   - `04-quick-notes.png`

On Windows, use `Win + Shift + S` to capture the screen. On Android, use the phone's screenshot buttons. Only use sample/demo information in screenshots.
