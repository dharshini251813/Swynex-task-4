# Lumora — Demo Video Script (about 60–90 seconds)

Hello everyone! This is Lumora, my Student Life Planner web application.

Lumora is designed to help students organize academic tasks, stay focused, and keep track of ideas in one place.

On the Overview page, users can see their total tasks, completed tasks, pending tasks, focus minutes, and daily progress.

In My Tasks, users can add a task, choose a category and priority, set a due date, search tasks, filter completed or pending items, edit details, mark tasks complete, or delete them.

The Focus Room includes a simple study timer with 15-, 25-, and 45-minute sessions. When a session finishes, Lumora records the completed focus minutes.

Quick Notes lets users save, edit, and delete reminders or project ideas.

I built Lumora using HTML, CSS, and JavaScript. The app uses browser local storage to keep tasks and notes on the same device, and its layout adapts to mobile and desktop screens.

This project helped me practise front-end development, JavaScript interactions, responsive design, and local storage. Thank you for watching!
